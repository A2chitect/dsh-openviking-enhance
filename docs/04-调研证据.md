## 4. 数据源（本项目实际用到的四个调用）

```bash
SID=dsh-session-7938b275-0a44-4c34-b961-6b312b15fd9d

# (a) 提交状态
$ curl -s "http://127.0.0.1:1933/api/v1/sessions/$SID"
{"status":"ok","result":{"session_id":"dsh-session-7938b275-…","message_count":10,
 "commit_count":1,"memories_extracted":{"total":8,"memory_write":4,"memory_edit":4},
 "last_commit_at":"2026-09-30T13:32:06.618Z","pending_tokens":0,"keep_recent_count":10,…}}

# (b) 归档目录（第 N 次提交 = 第 N 个 archive）
$ curl -s "http://127.0.0.1:1933/api/v1/fs/ls?uri=viking://user/default/sessions/$SID/history"
{"status":"ok","result":[{"uri":"…/history/archive_001","isDir":true,
 "modTime":"2026-09-30T13:32:06.000Z","abstract":"# Working Memory"}],…}

# (c) 影响记忆明细
$ curl -s "http://127.0.0.1:1933/api/v1/content/read?uri=…/archive_001/memory_diff.json"
{"status":"ok","result":"{\"archive_uri\":\"…\",\"extracted_at\":\"…\",
 \"operations\":{\"adds\":[{\"uri\":\"viking://user/default/memories/events/…/CIPT 状态实查确认暂停.md\",
   \"memory_type\":\"events\",\"after\":\"# Summary…\"}],
  \"updates\":[{\"uri\":\"…/entities/证书与CPE平台/myiapp.md\",\"before\":\"…\",\"after\":\"…\"}],
  \"deletes\":[]},
 \"summary\":{\"total_adds\":4,\"total_updates\":4,\"total_deletes\":0,\"total_skipped\":0}}"}

# (d) 进行中的提交
$ curl -s "http://127.0.0.1:1933/api/v1/tasks?task_type=session_commit&resource_id=$SID"
{"status":"ok","result":[{"task_id":"…","task_type":"session_commit","status":"completed",
 "result":{"memory_diff_uri":"viking://…/archive_001/memory_diff.json", …}}]}
```

要点：

- `content/read` 的 `result` 是**被字符串化的 JSON**，需要解析两次；
- `archive_00N` 存在但 `memory_diff.json` 404 ⇒ 抽取仍在进行（两阶段提交）；
- `/api/v1/tasks` 的记录会被清理（2026-09-30 的提交任务已查不到，10-01 的还在）
  ⇒ 历史必须走 archive 目录；
- `deletes[]` 用 `deleted_content` 而非 before/after（schema 有，实测未出现非空）。

### webServer 路由契约（`dsh-host-webserver@0.2.0-rc.2` 实测类型）

```ts
export type WebRouteKind = 'exact' | 'prefix'
export interface WebRoute {
  kind: WebRouteKind
  path: string                                   // 绝对路径，无尾斜杠
  handler: (req: IncomingMessage, res: ServerResponse) => void | Promise<void>
}
export declare class WebServer extends Service { register(route: WebRoute): () => void }
```

注意：**没有 `method` 字段**，方法判断要自己在 handler 里做。

### 包清单契约（asar 内 `dsh-package-manifest` README）

```ts
const manifest: DshPackageManifest = {
  name: 'example-dsh-plugin', version: '1.0.0',
  engines: { node: '>=24', dsh: '0.1.5-alpha.1' },   // ← engines.dsh 在顶层
  dsh: { manifestVersion: 1, bundle: { patch: './cordis.patch.yml' }, client },
}
```

本项目两处都声明了 `dsh` 版本范围（顶层 `engines.dsh` 是文档写法，
`dsh.engines.dsh` 是已装第三方插件在用的写法），因为官方说明
"installers and loaders do not enforce `dsh.manifestVersion` or `engines.dsh`"。
